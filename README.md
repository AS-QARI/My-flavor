# ذائقتي — دفتر المطاعم

تطبيق ويب عربي لتسجيل تجارب المطاعم: خريطة للأماكن، تقييم بالنجوم، ملاحظات وصور، وبحث وتصفية مشتركان بين الخريطة والدفتر. يدعم الوضع الداكن والفاتح ويحفظ اختيار المظهر على الجهاز، مع واجهة متجاوبة للجوال والكمبيوتر.

## استخدام قوقل ماب

من نافذة «أضف مطعمًا»، الصق رابط مشاركة المكان من قوقل ماب ثم اضغط «جلب الموقع». يدعم روابط المشاركة المختصرة وروابط المكان التي تحتوي إحداثياته، ويملأ اسم المكان عند توفره. راجع الدبوس قبل الحفظ؛ يمكنك نقله بالنقر أو السحب، أو اختيار وسط الخريطة بلوحة المفاتيح. رابط يعرض وسط الخريطة فقط لا يُعتبر موقعًا مؤكدًا للمطعم.

تفاصيل المطعم تحتوي «الاتجاهات في قوقل ماب» و«عرض المكان». يحتفظ التطبيق برابط المكان الأصلي؛ وإذا غيّرت الدبوس يدويًا يستخدم الإحداثيات الجديدة. الربط يستخدم [Maps URLs الرسمية](https://developers.google.com/maps/documentation/urls/get-started) ولا يحتاج مفتاح API. الخريطة التفاعلية داخل ذائقتي ما زالت Leaflet وOpenStreetMap؛ تضمين خريطة Google نفسها مع البحث عن الأماكن يتطلب إعداد Google Maps Platform منفصلًا.

## التشغيل محليًا

يتطلب المشروع Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000` في المتصفح. بيئة التطوير المحلية توفر مستخدمًا تجريبيًا لتسجيل الدخول.

## أوامر المشروع

```bash
npm run dev          # تشغيل بيئة التطوير
npm run build        # إنشاء نسخة الإنتاج
npm run lint         # فحص الشيفرة
npm run db:generate  # إنشاء ترحيلات قاعدة البيانات بعد تعديل المخطط
npm test             # التحقق من قراءة روابط قوقل والإحداثيات والاتجاهات
```

## بنية المشروع

- `app/` — الواجهات ومسارات API.
- `components/ui/` — عناصر الواجهة القابلة لإعادة الاستخدام.
- `db/` — مخطط قاعدة البيانات والاتصال بها.
- `drizzle/` — ترحيلات قاعدة البيانات.
- `public/` — الصور والأيقونات وملف تثبيت التطبيق.
- `public/fonts/` — الخط العربي محليًا مع ترخيصه، حتى يعمل بعد نقل مجلد المشروع.
- `wrangler.jsonc` — إعدادات نشر Cloudflare Workers وربط قاعدة البيانات والصور.

## التخزين والخصوصية

التجارب محفوظة في قاعدة D1، والصور في R2. كل طلب يربط البيانات بهوية المستخدم المسجّل، ومسارات الصور خاصة. ملف الإعدادات لا يحتوي على مفاتيح سرية.

الخريطة مبنية بـ Leaflet وOpenStreetMap، وتدعم السحب واللمس والتكبير بإصبعين وتحديد الموقع عبر المتصفح. يتطلب تحديد الموقع اتصال HTTPS وسماح المستخدم بالموقع على الآيفون.

## التطوير والنشر

يمكنك تعديل التصميم والميزات ثم تشغيل `npm run build` للتحقق. عند تعديل `db/schema.ts` شغّل `npm run db:generate` واحفظ ملفات الترحيل الجديدة داخل `drizzle/`.

المشروع مهيأ للنشر على Cloudflare Workers. بيانات المطاعم تبقى في D1، والصور في R2، وبيانات تسجيل الدخول تحفظ كأسرار في Cloudflare ولا تدخل GitHub.

### النشر على Cloudflare Workers

1. أنشئ قاعدة D1 باسم `dhaiqati-db` ومساحة R2 باسم `dhaiqati-files` من لوحة Cloudflare.
2. انسخ **Database ID** لقاعدة D1 وضعه بدل `REPLACE_WITH_YOUR_D1_DATABASE_ID` في `wrangler.jsonc`، ثم ارفع التعديل إلى GitHub.
3. في Workers & Pages أنشئ Worker من مستودع GitHub. اجعل أمر البناء `npm run build` وأمر النشر `npx wrangler deploy`.
4. من Worker > Settings > Variables and Secrets، أضف أسرار النصوص التالية: `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`SESSION_SECRET`. يجب أن يكون `SESSION_SECRET` عشوائيًا وبطول 32 حرفًا على الأقل.
5. بعد أول بناء ناجح، طبّق الترحيلات من جهازك بعد تسجيل دخول Wrangler:

```bash
npx wrangler d1 execute dhaiqati-db --remote --file drizzle/0000_simple_moonstone.sql
npx wrangler d1 execute dhaiqati-db --remote --file drizzle/0001_lazy_lord_hawal.sql
```

واجهة `/login` تحمي الدفتر. الجلسة موقعة ومخزنة في Cookie محمي؛ لا تضع اسم المستخدم أو كلمة المرور في الشيفرة أو في GitHub.

### التشغيل محليًا

انسخ `.dev.vars.example` إلى `.dev.vars` وضع قيمًا محلية، ثم شغّل `npm run dev`. هذا الملف مستثنى من Git.
