# ذائقتي — دفتر المطاعم

تطبيق ويب عربي داكن للجوال لتسجيل ذكريات المطاعم بشكل شخصي: خريطة للأماكن، تقييم بالنجوم، ملاحظات وصور، بحث وتصفية، مع واجهة محسّنة لشاشة iPhone 11 Pro Max وSafari على iOS.

## التشغيل محليًا

يتطلب المشروع Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000` في المتصفح. بيئة التطوير المحلية توفر مستخدمًا تجريبيًا لتسجيل الدخول.

## أوامر المشروع

```bash
npm run dev          # تشغيل بيئة التطوير
npm run build        # إنشاء نسخة الإنتاج
npm run lint         # فحص الشيفرة
npm run db:generate  # إنشاء ترحيلات قاعدة البيانات بعد تعديل المخطط
```

## بنية المشروع

- `app/` — الواجهات ومسارات API.
- `components/ui/` — عناصر الواجهة القابلة لإعادة الاستخدام.
- `db/` — مخطط قاعدة البيانات والاتصال بها.
- `drizzle/` — ترحيلات قاعدة البيانات.
- `public/` — الصور والأيقونات وملف تثبيت التطبيق.
- `.openai/hosting.json` — إعدادات قاعدة البيانات وتخزين الصور والنشر الحالي.

## التخزين والخصوصية

التجارب محفوظة في قاعدة D1، والصور في R2. كل طلب يربط البيانات بهوية المستخدم المسجّل، ومسارات الصور خاصة. ملف الإعدادات لا يحتوي على مفاتيح سرية.

الخريطة مبنية بـ Leaflet وOpenStreetMap، وتدعم السحب واللمس والتكبير بإصبعين وتحديد الموقع عبر المتصفح. يتطلب تحديد الموقع اتصال HTTPS وسماح المستخدم بالموقع على الآيفون.

## التطوير والنشر

يمكنك تعديل التصميم والميزات ثم تشغيل `npm run build` للتحقق. عند تعديل `db/schema.ts` شغّل `npm run db:generate` واحفظ ملفات الترحيل الجديدة داخل `drizzle/`.

المشروع مهيأ للنشر عبر OpenAI Sites. ويمكن تكييفه لاحقًا لأي استضافة تدعم Cloudflare Workers وD1 وR2.
